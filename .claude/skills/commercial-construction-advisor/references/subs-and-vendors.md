# Subcontractors & vendors

Source authorities: AGC subcontractor best practices, SDI carrier underwriting, NASBP, ConsensusDocs/AIA subcontract forms.

## Prequalification

- [ ] Financial review (audited or reviewed financials, working capital, single-job capacity)
- [ ] Bonding capacity check
- [ ] Safety prequal (EMR, OSHA logs, written program)
- [ ] Quality history
- [ ] References from owners and other GCs
- [ ] Insurance limits and additional-insured endorsements
- [ ] Tiered status (Preferred / Approved / Conditional / Do-Not-Use)

## Default insurance

- [ ] SDI program economics (premium % of subcontract value)
- [ ] SDI vs. subcontractor bonds — when to require which
- [ ] Single sub concentration limit (% of any one project)

## Partner programs

- [ ] Annual sub partner conference
- [ ] Diversity sub mentorship (MBE/WBE/DBE/SDVOSB)
- [ ] Joint safety stand-downs
- [ ] Payment-velocity programs (early-pay discounts, supply-chain finance)

## Vendor master discipline

- [ ] Single source of truth (ERP)
- [ ] W-9 / 1099 hygiene
- [ ] COI tracking with auto-renewal alerts
- [ ] Diversity classification tagging

## Decision rubric: Sub default response

- [ ] Early-warning indicators (delayed mobilization, payroll complaints, missing material deliveries)
- [ ] Cure-notice → takeover → SDI claim sequence
