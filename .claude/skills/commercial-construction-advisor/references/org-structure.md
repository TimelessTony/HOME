# Org structure & roles by revenue band

Source authorities: FMI org-design studies, ENR Top 400 org charts (public), AGC role frameworks, CII project leadership research.

## Org chart templates

- [ ] $50M GC: founder-led, 1 ops leader, 1 estimator, 1 controller, 3–5 PMs, 4–6 Supers
- [ ] $100M GC: + Director of Preconstruction, + dedicated CFO, + Safety Director
- [ ] $250M GC: + COO, + CHRO, + VDC lead, + regional or sector verticals
- [ ] $400M GC: + Chief Strategy / BD Officer, + multi-region GMs, + Talent / L&D function, + General Counsel (or fractional)

## Role charters (RACI)

- [ ] Project Executive
- [ ] Senior Project Manager
- [ ] Project Manager
- [ ] Project Engineer
- [ ] Superintendent (General, Area, Assistant)
- [ ] Estimator (Chief, Senior, Estimator, Estimating Coordinator)
- [ ] Preconstruction Manager
- [ ] VDC / BIM Lead
- [ ] Safety Manager
- [ ] Quality Manager

## Span-of-control norms

- [ ] PM workload: $20–40M of revenue under management
- [ ] Superintendent workload: $15–25M, single project preferred over $40M
- [ ] PE-to-PM ratio
- [ ] Estimator-to-pursuit ratio

## Decision rubric: Hire vs. promote vs. outsource

- [ ] Strategic vs. tactical role test
- [ ] Build-vs-buy test for emerging functions (VDC, sustainability, data)
- [ ] Fractional / advisory paths for CFO, GC, CHRO at sub-$100M
