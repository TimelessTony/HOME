# Safety leadership

Source authorities: OSHA, BLS, AGC Safety, ABC STEP, CII safety research, ENR Safety Awards.

## Targets

- [ ] TRIR < 1.0 (best-in-class < 0.5)
- [ ] DART < 0.5
- [ ] EMR < 0.75
- [ ] Lost-time incident rate trend
- [ ] Near-miss reporting rate (leading indicator — high is good)

## Program elements

- [ ] Written safety program (site-specific safety plan template)
- [ ] Job Hazard Analysis (JHA) discipline before each task
- [ ] Pre-task plan / stretch-and-flex
- [ ] OSHA 10 / OSHA 30 staffing
- [ ] First-aid / CPR / AED coverage on every site
- [ ] Stop-work authority for every worker
- [ ] OSHA VPP path for mature firms

## Behavior-based safety

- [ ] Observation cards with positive-feedback orientation
- [ ] Leading-indicator dashboard (observations, JHAs, near-misses, audits)
- [ ] Executive site walks cadence

## Sub safety prequalification

- [ ] EMR cap (typical < 1.0)
- [ ] OSHA 300/300A review
- [ ] Written program and training records
- [ ] Site-specific safety plan submission

## Incident response

- [ ] Recordable incident response tree
- [ ] OSHA reporting timelines (fatality 8h, hospitalization/amputation/loss-of-eye 24h)
- [ ] Drug & alcohol testing posture (post-incident)
- [ ] Root-cause analysis (5 whys, TapRooT)
- [ ] Lessons-learned distribution
