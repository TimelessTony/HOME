# KPIs & operating cadence

Source authorities: CFMA, FMI, CII, AGC, public 10-Ks.

## Leading indicators

- [ ] Pipeline coverage ratio (target 4–6x)
- [ ] Hit rate by delivery method (negotiated vs. hard bid vs. CMAR)
- [ ] Backlog months (target 12–18)
- [ ] Backlog GP %
- [ ] RFI cycle time
- [ ] Submittal cycle time
- [ ] Schedule Performance Index (SPI)
- [ ] Cost Performance Index (CPI)
- [ ] Safety: near-miss reporting rate, leading-indicator audits

## Lagging indicators

- [ ] Gross profit fade (target <10%, best in class <5%)
- [ ] Change-order rate (owner-add vs. cost-recovery)
- [ ] Days Sales Outstanding (target <60)
- [ ] Days Payable Outstanding
- [ ] Cash conversion cycle
- [ ] EMR (target <0.75)
- [ ] TRIR (target <1.0)
- [ ] Voluntary turnover (target <12% salaried, <20% craft)
- [ ] Customer NPS (target >60)

## Operating cadence templates

- [ ] Weekly project review (PX/PM/Super)
- [ ] Monthly OAC + WIP review
- [ ] Quarterly business review (sector / region)
- [ ] Annual strategy + comp planning

## Decision rubric: Fade root-cause tree

- [ ] Estimate quality vs. execution vs. scope vs. schedule branches
- [ ] Required corrective actions by branch
